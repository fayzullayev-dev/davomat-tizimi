# Как запустить проект

## 1. Что нужно установить (один раз)

1. **Node.js** версии 18 или новее: https://nodejs.org (кнопка «LTS»).
   Проверка в терминале:
   ```bash
   node -v
   npm -v
   ```
2. **Git**: https://git-scm.com/downloads

## 2. Скачать проект

```bash
git clone https://github.com/fayzullayev-dev/davomat-tizimi.git
cd davomat-tizimi
```

## 3. Установить зависимости (один раз, и после каждого изменения package.json)

```bash
npm install
```

## 4. Запустить сайт

```bash
npm run dev
```

Откройте в браузере адрес, который появится в терминале (обычно **http://localhost:5173**).

Чтобы остановить сайт, нажмите в терминале `Ctrl + C`.

## 5. Логины для входа

| Роль | Логин | Пароль |
|---|---|---|
| Суперадмин (полный доступ) | `superadmin` | `admin123` |
| Директор (только просмотр) | `direktor` | `direktor123` |
| Отдел кадров | `kadrlar` | `kadrlar123` |

## 6. Сборка для сервера

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`. Их можно положить на любой веб-сервер (nginx и т. п.).

## 7. Работа с Git (дома и на работе)

После изменений отправьте их на GitHub:
```bash
git add .
git commit -m "что изменил"
git push
```

На другом компьютере заберите последние изменения:
```bash
git pull
npm install
npm run dev
```

## Важно

- Сейчас все данные тестовые и хранятся в памяти браузера: после перезагрузки страницы изменения сбрасываются.
- Все запросы к данным находятся в одном файле `src/services/api.ts`. Чтобы подключить настоящий бэкенд, нужно заменить только его.
